# Промт для ИИ-агента в Битриксе: развернуть сайт CARVIC на нашем сервере

> Скопируйте всё, что ниже линии, в агента целиком. Доступы (раздел 2) впишите **в окне агента**,
> а не в этот файл: репозиторий публичный, пароли в нём увидят все.

---

## Роль и задача

Ты — инженер, который разворачивает готовый сайт автозапчастей **CARVIC** (ООО «Карвик», Иркутск)
на сервере компании под 1С-Битрикс. Дизайн и тексты уже утверждены владельцем. Твоя задача —
**выложить сайт как есть, подключить приём заявок и проверить**, а не переделывать его.

Работай по этапам ниже. После каждого этапа присылай владельцу короткий отчёт: что сделано,
ссылка, что проверено, что заблокировано. Если требование неясно или нужно решение
владельца — остановись и спроси, не додумывай.

## 3. Этап 1 — выложить сайт на тестовый домен

1. Скачай ветку `design/light-home`, возьми содержимое папки `site/`.
2. Выложи его в отдельную папку тестового поддомена, **не затирая** установленный Битрикс
   (папки `/bitrix/`, `/upload/`, `/local/` не трогать). Если тестовый поддомен делит
   document root с боевым сайтом — остановись и спроси владельца.
3. Включи HTTPS (Let’s Encrypt или сертификат хостинга).
4. Настрой веб-сервер:
   - типы файлов: `.webp` → `image/webp`, `.mp4` → `video/mp4`, `.svg` → `image/svg+xml`, `.md` → `text/markdown; charset=utf-8`;
   - сжатие gzip/brotli для `html, css, js, svg, md, xml`;
   - кэш: `index.html` — `no-cache`; `css/`, `js/` — до 1 часа (файлы без хеша в имени, долгий кэш оставит старые версии у посетителей); `img/`, `assets/` — 30 дней;
   - для `.mp4` — поддержка запросов Range (видео в баннере);
   - запросы на `/api/…` пока отдавать `404` в JSON (`{"ok":false,"message":"…"}`), а не HTML-страницу Битрикса.
5. Проверь (раздел 7), пришли ссылку владельцу.

## 4. Этап 2 — приём заявок (минимум, без которого сайт нельзя открывать)

Без сервера формы сайта ничего не отправляют. Сделай PHP-обработчики (в `/local/` или отдельной папке —
на твой выбор, но доступны они должны быть строго по путям ниже). Каждый принимает JSON и
отвечает JSON. Успех — `200 {"ok":true,"id":"<номер заявки>","note":"<текст для посетителя>"}`.
Ошибка — `4xx {"ok":false,"message":"<понятный текст по-русски>"}`.

| Путь | Метод | Поля запроса | Что делать |
|---|---|---|---|
| `/api/inquiries` | POST | `kind` (`selection`/`price`/`contact`…), `name`, `contact`, `message`, `article`, `brand`, `vin`, `outletId`, `company`, `consentRequest` | Лид в Битрикс24 (или письмо на info@carvic.ru) |
| `/api/callback-request` | POST | `name`, `phone`, `message`, `company`, `consentRequest` | Лид «Обратный звонок» |
| `/api/opt/register` | POST | `organization`, `inn`, `kpp`, `contactName`, `phone`, `email`, `acceptTerms`, `acceptOpt`, `acceptAds` | Лид «Заявка оптовика» |
| `/api/account/register` | POST | `firstName`, `lastName`, `phone`, `email`, `car{label,vin,plate,consentGarage}`, `acceptAds`, `company` | Пока **не реализовывать**: верни `501` — сайт сам перешлёт регистрацию заявкой в `/api/inquiries` |

Правила для всех обработчиков:
- `company` — **ловушка для ботов** (скрытое поле). Если оно не пустое — ответь `200 ok`, но заявку не создавай.
- Без `consentRequest: true` (у оптовика — без `acceptTerms` и `acceptOpt`) — отказ `400`.
- Телефон: оставь цифры, приведи к `+7XXXXXXXXXX`; проверь длину.
- Ограничь частоту: не больше 5 заявок с одного IP за 10 минут.
- Ограничь размер тела запроса (32 КБ) и длину полей; экранируй всё, что уходит в CRM или письмо.
- Не логируй персональные данные в открытые журналы.
- В `note` верни текст, например «Менеджер перезвонит в рабочее время».

Остальные адреса `/api/…`, которые вызывает сайт (каталог, цены, остатки, кабинет, корзина, заказ),
**на этом этапе не делай**. Сайт без них показывает «Раздел временно недоступен» с телефоном
и кнопкой «Оставить заявку» — это ожидаемо. Полный список адресов — в разделе 8.

## 5. Этап 3 — перенос на carvic.ru (только по команде владельца)

1. Владелец решает, что делать с текущим сайтом на carvic.ru (сохранить копию, перенести).
2. Сделай резервную копию текущего сайта и базы до любых изменений.
3. Выложи `site/` на боевой домен, перенеси настройки этапов 1–2.
4. В `site/index.html` строку `<meta name="robots" content="noindex, nofollow">` убери **только по
   письменному решению владельца** (сейчас сайт закрыт от поисковиков намеренно). Тогда же добавь
   `robots.txt` со ссылкой на `https://carvic.ru/sitemap.xml`.
5. Повтори проверки раздела 7 на боевом домене.

## 6. Важно: не сломать

1. **Демо-режим.** Если сайт открыт не на `carvic.ru` или его поддомене и сервер не отвечает, включается
   режим предпросмотра: примерные товары и **демо-вход в кабинет по логину «1» и паролю «1»**.
   Поэтому тест — только на поддомене `*.carvic.ru`, не на IP и не на чужом домене.
2. Не меняй дизайн, тексты, цены, акции, юридические документы. Опечатку или баг — сообщи, а не правь молча.
3. Файл `js/admin.js` подключён в `index.html`, но в репозитории его нет (решение владельца ещё не принято).
   Запрос к нему даёт 404 — это известно, не создавай админку сам. Страница `#/admin` честно пишет «Админка не подключена».
4. Не храни ключи, пароли и вебхуки в файлах сайта (всё в `site/` видно любому посетителю).
5. Юридические документы (`site/legal/*.md`) — черновики с пометкой «проект, на согласовании». Не публикуй их как
   окончательные и не удаляй пометку без решения владельца и юриста.

## 7. Проверка после каждого выкладывания

Открой сайт на компьютере (ширина 1440) и телефоне (390), в светлой и тёмной теме (переключатель справа вверху).

- [ ] В консоли браузера нет необработанных ошибок JavaScript (`Uncaught …`). Допустимы: 404 на `/api/…` и `js/admin.js`, записи «Сервер цен/кабинета недоступен» на каталоге, поиске и оформлении, пока нет этапов 4+
- [ ] Главная: заставка с логотипом (один раз за сеанс), баннер с видео официанта играет без звука, второй слайд «−5% за отзыв»
- [ ] Разделы открываются: `#/catalog`, `#/stores`, `#/wholesale`, `#/promo`, `#/blog`, `#/about`, `#/about/team`, `#/contacts`, `#/requisites`, `#/returns`, `#/legal/privacy`
- [ ] Окна открываются поверх страницы: «Заказать звонок», «Войти», «Регистрация», «Оставить заявку»
- [ ] Заявка с главной («Не нашли деталь?»), обратный звонок и заявка оптовика доходят в CRM/на почту; пустое согласие — отказ; заполненное поле-ловушка — заявка не создаётся
- [ ] Регистрация уходит заявкой (пока `/api/account/register` отвечает 501)
- [ ] На телефоне нет горизонтальной прокрутки
- [ ] Видео `img/promos/komplekt-butler.mp4` отдаётся с `Content-Type: video/mp4` и поддержкой Range
- [ ] HTTPS без предупреждений, http → https перенаправляет

## 8. Справка: все адреса `/api`, которые вызывает сайт (на будущее, этапы 4+)

Каталог, цены и остатки из 1С: `GET /api/catalog/state`, `GET /api/feed/catalog`, `GET /api/feed/search`,
`GET /api/feed/product?id=`, `GET /api/feed/suggest?q=`, `POST /api/feed/check`, `POST /api/feed/paste`.
Подбор: `GET /api/vehicle/by-plate?plate=` (по госномеру), `GET /api/rossko/search`, `GET /api/rossko/status`.
Кабинет (сессия в HttpOnly-cookie, CSRF в заголовке `X-CSRF-Token`, заказ — с `Idempotency-Key`):
`/api/account/status`, `/me`, `/login`, `/login/sms`, `/logout`, `/register`, `/profile`, `/settings`, `/garage`,
`/notebook`, `/cart`, `/cart/import`, `/checkout`, `/orders`, `/balance`, `/returns`, `/wholesale-returns`,
`/outlet`, `/methods`, `/consents/withdraw`, `/delete`, `/delete/confirm`, `/act/stop`, `/feed/*`.
Прочее: `GET /api/auth/status`, `GET /api/legal/placeholders`, `GET /api/pages/delivery`, `GET /api/pages/returns`.

Контракт полей — в коде: `site/js/api/account.js`, `site/js/api/onec.js`, `site/js/app.js`.
Цены на сайте **никогда не считаются в браузере**: только сервер, из 1С. Если цены нет — сайт пишет «цена по запросу».
Эти этапы не начинай без отдельного задания владельца.
