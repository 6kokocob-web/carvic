# Проверка сайта CARVIC — 24.11.2026

Ветка `design/light-home`. Автоматический обход **41 адреса** в двух режимах:
1) тестовая ссылка без сервера (режим предпросмотра); 2) как на боевом домене `carvic.ru` без сервера.
Каждая страница — на компьютере (1440, светлая тема) и телефоне (390, тёмная тема): ошибки JavaScript,
битые картинки и файлы, горизонтальная прокрутка, пустые страницы, все внутренние ссылки (91 шт.),
плюс просмотр скриншотов глазами.

## Требует сервера (без него на carvic.ru не работает)

На боевом домене без сервера не работают: каталог, поиск, цены и остатки, корзина и оформление заказа,
вход и кабинет, **все формы заявок** (подбор, обратный звонок, регистрация, оптовик).
Минимум для запуска — приём заявок: см. `docs/DEPLOY-PROMPT.md`, этап 2.
