# CARVIC на хостинге Рег.ру — как развернуть

Архив `carvic-regru.zip` — готовый сайт для обычного хостинга Рег.ру (Apache + PHP):
сайт целиком, настройки сервера `.htaccess` и обработчики заявок `api/*.php`.

## Что будет работать после загрузки

| Работает | Пока не работает (нужен сервер с 1С) |
|---|---|
| Все страницы, акции, блог, магазины, карта, контакты, юр. документы | Каталог с ценами и остатками, поиск по артикулу |
| Заявка «Не нашли деталь?», «Оставить заявку», «Заказать звонок» → письмо на info@carvic.ru | Корзина и оформление заказа |
| Заявка оптовика → письмо | Вход и личный кабинет |
| Регистрация → уходит менеджеру заявкой | — |

Там, где нужен сервер с 1С, посетитель видит «Раздел временно недоступен», телефон и кнопку «Оставить заявку».
Демо-товары и демо-вход «1/1» в этой сборке выключены на любом домене.

## Шаги

1. **Хостинг.** Нужен тариф с PHP 7.4 или новее (подходит любой тариф «Хостинг» Рег.ру).
   В панели (ISPmanager или Host-панель) → «Сайты» → выберите PHP 8.x для домена.
2. **Резервная копия.** Если на домене уже есть сайт — скачайте копию папки сайта (и базы, если есть). Файлы загрузки заменят `index.html`.
3. **Загрузка.** Панель → «Файловый менеджер» → папка сайта (обычно `www/carvic.ru/` или `public_html/`).
   Загрузите `carvic-regru.zip` → правой кнопкой «Извлечь». После распаковки в папке должны лежать
   `index.html`, `.htaccess`, папки `css`, `js`, `img`, `api`, `legal`, `content`. Сам zip удалите.
   (Файл `.htaccess` скрытый — включите в менеджере «показывать скрытые файлы», чтобы его увидеть.)
4. **Почта для заявок.** В панели создайте ящик `noreply@carvic.ru` (с него хостинг отправляет письма, иначе они попадут в спам).
   Заявки приходят на `info@carvic.ru`. Поменять адреса или добавить Битрикс24: скопируйте
   `api/config.sample.php` в `api/config.php` и поправьте значения.
5. **SSL.** Панель Рег.ру → «SSL-сертификаты» → бесплатный сертификат для carvic.ru и www.carvic.ru.
   Когда он выпущен (обычно до суток) — в `.htaccess` уберите `#` в начале пяти строк блока «http → https».
6. **Проверка** (см. ниже).

## Проверка после загрузки

- [ ] Открывается https://carvic.ru — заставка с логотипом, баннер с видео официанта
- [ ] Меню, разделы, акции, блог, магазины открываются; на телефоне нет прокрутки вбок
- [ ] Отправьте заявку с главной («Не нашли деталь?») и «Заказать звонок» — письма пришли на info@carvic.ru
- [ ] Заявка без галочки согласия не уходит
- [ ] https://carvic.ru/api/_lib.php — «Доступ запрещён» (403)
- [ ] https://carvic.ru/api/catalog/state — JSON «Раздел временно недоступен» (404)

Если письма не приходят: проверьте, что ящик `noreply@carvic.ru` создан на этом же хостинге, и посмотрите папку «Спам».

## Что решить до открытия для поисковиков

В `index.html` стоит `<meta name="robots" content="noindex, nofollow">` — сайт закрыт от Яндекса и Google.
Уберите эту строку, когда юр. документы согласованы и сайт готов к людям (см. `docs/AUDIT.md`).

## Пересобрать архив из репозитория

```bash
bash deploy/regru/build.sh
```

Архив появится в `dist/carvic-regru.zip`.
